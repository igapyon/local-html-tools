local-html-tools MD3 Component Reference

コンポーネント実物 + CSSクラス + HTML記述例のリファレンス

このプロジェクトの Material Design 対応は、各HTMLファイル冒頭の `:root` にある CSS 変数（`--md-sys-*`）を前提にしています。 ここには、`docs` 配下を含む全HTMLから抽出したトークンの総和（重複は除外）をまとめています。
