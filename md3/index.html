local-html-tools MD3 Component Catalog

実運用ベースの、コンポーネント実物 + Selectors + Origin/Rationale + Preview Code + Usage（実利用リンク）の統合リファレンス

トークン方針（:root / --md-sys-*）
ここに掲載する `Token Spec` を正本とし、各 `docs/*.html` にコピーして利用します。 `docs/*.html` 側で改善を見つけた場合は、適用後にこの `md3` 側へフィードバックして更新します。
参考: `Token Spec` / `Core Spec` は `md3/spec/*.css` でも管理する。
Core（共通）
`Core Spec` も正本はここ（および `md3/spec/core-spec.css`）。各 `docs/*.html` はコピーして利用し、改善は `md3` へ還元します。
Screen-specific（画面依存）

Core Components

ここにある各コンポーネントは、すぐに `class` をコピーして利用できるよう実物 + HTML例を配置している。
注: プレビューは実運用ページから断片的にコピーしているため、`onclick` / `onchange` が未定義関数を参照する場合があります（仕様として許容）。同じ理由で、`id` が重複する断片が含まれる場合があります。
トグル系は `md-switch` に統一済みです。
