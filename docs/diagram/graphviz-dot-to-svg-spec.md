# graphviz-dot-to-svg 仕様

## 目的

Graphviz DOTテキストを入力し、ブラウザ上でSVGを生成する。生成したSVGはプレビュー、コピー、保存を可能にする。

## 対象ユーザー

- テキストで図を定義したいユーザー
- ローカル完結（オフライン）で図を生成したいユーザー
- PowerPoint等へSVGを流用したいユーザー

## 入力

- DOTソース（必須）
- レイアウトエンジン（必須）
  - `dot`
  - `neato`
  - `fdp`
  - `sfdp`
  - `circo`
  - `twopi`

## 出力

- レンダリング済みSVGプレビュー
- SVGテキスト
- ダウンロード:
  - `graphviz-diagram.svg`

## UI方針

- `md3/spec/token-spec.css` と `md3/spec/core-spec.css` の設計を踏襲
- タイトル右に `i` ツールチップを配置
- 主要項目（入力、エンジン、プレビュー、SVGテキスト）に `i` ツールチップを配置
- 操作は `レンダリング` / `SVG保存` / `コピー` を明示
- 成功時はトーストで短く通知

## エラーハンドリング

- 入力空欄時はエラーメッセージを表示し、処理を中断する
- DOTパース/レイアウト失敗時はエラーメッセージを表示する
- 行番号が取得できる場合は、該当行をフォーカスする（軽量ハイライト）

## 入力正規化

- 先頭・末尾の空行は除去する
- 先頭が ```` ``` ```` または ```` ```任意キーワード ````、末尾が ```` ``` ```` の場合はフェンスを除去する

## 永続化

- レイアウトエンジン選択を `localStorage` に保存し、次回起動時に復元する

## オフライン要件

- GraphvizレンダラはJavaScript/wasm資産をローカル同梱して使用する
- 実行時にCDNや外部ネットワークへ依存しない
- ツール本体は単一HTMLで完結する

## 非機能要件

- 中規模DOT（数百ノード未満）で実用的な応答時間を目標とする
- モバイル幅でも操作可能なレイアウトとする

## 非対応（初期）

- PNG/PDF出力
- 自動レイアウト微調整UI（細かなGraphviz属性編集支援）
- 複数ファイル連携（import等）
