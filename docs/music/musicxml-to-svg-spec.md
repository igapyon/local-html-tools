# musicxml-to-svg 仕様

## 目的

MusicXMLを入力し、ブラウザ上で楽譜SVGを生成する。生成したSVGはプレビュー、コピー、保存を可能にする。

## 対象ユーザー

- MusicXMLから素早く楽譜画像を生成したいユーザー
- ローカル完結（オフライン）で楽譜を扱いたいユーザー
- SVGを資料やスライドへ流用したいユーザー

## 入力

- MusicXMLソース（必須）
- または MusicXMLファイル読込（`.musicxml` / `.xml`）
- レンダリング設定（初期は最小）
  - 縮尺（`scale`）
  - 余白（`pageMargin*`）
  - ページ幅（`pageWidth`）

## 出力

- レンダリング済みSVGプレビュー
- SVGテキスト
- ダウンロード:
  - `musicxml-score-page-XXX.svg`（現ページ）
  - `musicxml-score-pages.zip`（全ページSVG）

## UI方針

- `md3/spec/token-spec.css` と `md3/spec/core-spec.css` の設計を踏襲
- タイトル右に `i` ツールチップを配置
- 主要項目（入力、設定、プレビュー、SVGテキスト）に `i` ツールチップを配置
- 操作は `レンダリング` / `SVG保存` / `コピー` を明示
- 複数ページ時は `前へ` / `次へ` でページ切替を可能にする
- 成功時はトーストで短く通知

## エラーハンドリング

- 入力空欄時はエラーメッセージを表示し、処理を中断する
- XMLパース/レンダリング失敗時はエラーメッセージを表示する
- 行番号が取得できる場合は、該当行をフォーカスする（軽量ハイライト）

## 入力正規化

- 先頭・末尾の空行は除去する
- 先頭が ```` ``` ```` または ```` ```任意キーワード ````、末尾が ```` ``` ```` の場合はフェンスを除去する

## 永続化

- レンダリング設定（縮尺・余白・ページ幅）を `localStorage` に保存し、次回起動時に復元する

## オフライン要件

- 楽譜レンダラは Verovio のJavaScript/wasm資産をローカル同梱して使用する
- 実行時にCDNや外部ネットワークへ依存しない
- ツール本体は単一HTMLで完結する

## 非機能要件

- 一般的な単一楽曲（数ページ程度）で実用的な応答時間を目標とする
- モバイル幅でも操作可能なレイアウトとする

## 非対応（初期）

- PNG/PDF出力
- 再生機能（MIDI/オーディオ）
- 楽譜編集UI（ノート単位編集）
- 複数ファイル連携（include相当）

## 実装メモ

- レンダリングエンジン: Verovio（OSS）
- 出力はSVGを主とし、PowerPoint等への貼り付け互換は別途検証対象とする
