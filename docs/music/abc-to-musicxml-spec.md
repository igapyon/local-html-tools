# abc-to-musicxml 仕様

## 目的

ABC記法を入力し、ブラウザ上でMusicXMLを生成する。生成したMusicXMLはプレビュー、コピー、保存を可能にする。

## 対象ユーザー

- ABC記法をMusicXMLへ変換して他ツールへ連携したいユーザー
- ローカル完結（オフライン）で楽譜データ変換したいユーザー
- ChatGPT等で作成したABCを標準交換形式へ変換したいユーザー

## 入力

- ABCソース（必須）
- または ABCファイル読込（`.abc` / `.txt`）
- 変換設定（初期は最小）
  - タイトル未指定時の既定値
  - 作曲者未指定時の既定値
  - 出力フォーマット（`score-partwise` 固定）

## 出力

- 生成済みMusicXMLテキスト
- 生成結果の簡易プレビュー（任意）
- ダウンロード:
  - `score.musicxml`

## UI方針

- `md3/spec/token-spec.css` と `md3/spec/core-spec.css` の設計を踏襲
- タイトル右に `i` ツールチップを配置
- 主要項目（入力、設定、出力）に `i` ツールチップを配置
- 操作は `変換` / `MusicXML保存` / `コピー` を明示
- 成功時はトーストで短く通知

## 変換ポリシー（MVP）

- 明示的に対応するABC要素のみをMusicXMLへ変換する
  - ヘッダ: `T`, `M`, `L`, `K`, `C`
  - 本文: 単旋律ノート列、休符（`z`）、小節線（`|`）
  - 長さ指定（例: `C`, `C2`, `C/2`）
  - オクターブ記号（`,` / `'`）
- 非対応要素はエラーまたは警告として通知する
  - 装飾記号、連符、和音、複数声部、歌詞、繰り返し記号の高度機能

## エラーハンドリング

- 入力空欄時はエラーメッセージを表示し、処理を中断する
- ABC構文解釈失敗時はエラーメッセージを表示する
- 行番号が取得できる場合は、該当行をフォーカスする（軽量ハイライト）
- 非対応記法検出時は、該当トークンを含む警告を表示する

## 入力正規化

- 先頭・末尾の空行は除去する
- 先頭が ```` ``` ```` または ```` ```任意キーワード ````、末尾が ```` ``` ```` の場合はフェンスを除去する

## 永続化

- 変換設定（既定タイトル/作曲者など）を `localStorage` に保存し、次回起動時に復元する

## オフライン要件

- 変換ロジックはJavaScript資産をローカル同梱して使用する
- 実行時にCDNや外部ネットワークへ依存しない
- ツール本体は単一HTMLで完結する

## 非機能要件

- 短〜中程度のABC（数百小節未満）で実用的な応答時間を目標とする
- モバイル幅でも操作可能なレイアウトとする

## 非対応（初期）

- 双方向変換（MusicXML→ABC）
- 完全なABC仕様網羅
- 版面情報（細かなレイアウト）の忠実再現
- PNG/PDF出力

## 実装メモ

- 生成したMusicXMLは `musicxml-to-svg.html` で検証可能とする
- MVPでは「変換可能な範囲を明示し、壊れた出力を出さない」ことを優先する
