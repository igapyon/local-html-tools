# musicxml-to-midi 仕様（草案）

## 目的

MusicXML を入力し、ローカル完結で MIDI ファイル（`.mid`）を生成して保存できるようにする。

## 前提方針

- MusicXML の読み込み・解釈は自前 JavaScript 実装（`DOMParser`）で行う
- MIDI 生成は OSS の JavaScript ライブラリを利用する

## ライブラリ選定方針

### MVP 採用

- **`midi-writer-js` を採用**
- 理由:
  - MIDI 書き出し用途に直結した API で実装が軽い
  - 単一 HTML への同梱・ローカル完結構成に載せやすい
  - MVP（単旋律・基本テンポ/拍子）を短期間で実装しやすい

### 将来拡張時の再検討

- 高度編集（既存 MIDI の詳細編集、複雑なトラック操作、より高度な変換要件）が必要になった場合は **`@tonejs/midi` を再検討**する

## スコープ（MVP）

- 対象入力: `score-partwise` の先頭 `part`
- 変換対象:
  - `note`（pitch/rest）
  - `duration` / `divisions`
  - `tempo`（取得できる範囲）
  - `time`（拍子）
- 非対応（初期）:
  - 複雑な装飾、スラー/タイの厳密再現
  - 複数声部の厳密再現
  - 発想記号の網羅

## 出力

- `score.mid` ダウンロード
- 変換サマリー表示（トラック数、ノート数、テンポなど）
- 警告表示（スキップ要素）

## 補足

この仕様は「まず確実に動く MVP」を優先するための選定メモを兼ねる。
