# musicxml-to-abc 仕様

## 目的

MusicXML を入力し、ブラウザ上で ABC 記法テキストを生成する。生成した ABC はプレビュー、コピー、保存を可能にする。

## 対象ユーザー

- MusicXML から軽量なテキスト楽譜（ABC）へ変換したいユーザー
- ローカル完結（オフライン）で楽譜データ変換したいユーザー
- ChatGPT などで ABC 再編集したいユーザー

## 入力

- MusicXML ソース（必須）
- または MusicXML ファイル読込（`.musicxml` / `.xml`）
- 変換設定
  - タイトル未指定時の既定値
  - 作曲者未指定時の既定値
  - ABC 既定音価（L:）

## 出力

- 生成済み ABC テキスト
- 生成結果の簡易プレビュー
- ダウンロード
  - `score.abc`

## UI方針

- `abc-to-musicxml.html` と同系の UI を踏襲
- タイトル右に `i` ツールチップを配置
- 主要項目（入力、設定、出力）に `i` ツールチップを配置
- 操作は `変換` / `ABC保存` / `コピー` を明示
- 成功時はトーストで短く通知

## 変換ポリシー（MVP）

- 明示的に対応する MusicXML 要素のみ ABC へ変換する
  - `score-partwise` の先頭 `part` を対象
  - ヘッダ: `title/composer`, `time`, `key`
  - 本文: 単旋律 `note/rest`, `duration`, `pitch(step/alter/octave)`, `measure`
- 非対応要素は警告またはスキップ
  - 複数声部（`backup`/`forward`/voice差分）
  - 和音（`chord`）
  - タイ/スラー/装飾記号/歌詞
  - 連符や複雑な版面情報

## エラーハンドリング

- 入力空欄時はエラーメッセージを表示し、処理を中断
- XML パース失敗時はエラー表示
- 必須構造（`part` など）不足時はエラー表示
- 非対応要素検出時は警告一覧を表示

## 入力正規化

- 先頭・末尾の空行を除去
- 先頭が ```` ``` ```` または ```` ```任意キーワード ````、末尾が ```` ``` ```` の場合はフェンスを除去

## 永続化

- 変換設定（既定タイトル/作曲者/既定音価）を `localStorage` に保存し、次回起動時に復元

## オフライン要件

- 変換ロジックはブラウザ標準 API（DOMParser）で実装
- CDN や外部通信に依存しない
- ツール本体は単一 HTML で完結

## 非機能要件

- 中規模（数百小節程度）の MusicXML で実用的な応答時間を目標
- モバイル幅でも操作可能なレイアウト

## 非対応（初期）

- 完全な MusicXML 仕様網羅
- 複数パートの厳密な ABC 多声部出力
- PNG/PDF 出力
