# prompt-definitions-popular

`P` 系列は、世間で広く使われている、または普及度の高い定番プロンプトを配置するための系列です。

ここでいう `Popular` は、「自分の実務で正本として定着している」という意味ではありません。  
`A` 系列のように日常業務で実際に使っている基本系列とは区別しつつ、世間的には有用性が高く、広く見られるプロンプトを整理して置くための枠です。

## 役割

`P` 系列は、次のような目的で使います。

- 世間で普及している定番プロンプトを整理する
- 自分の実務ではまだ採用していないが、有用そうな型を保持する
- `A` 系列へ昇格させる前の観察対象として置く
- `S` 系列のような派生提案ではなく、世間的な定番として位置づける

## 系列の考え方

- `A` 系列:
  - 自分の実務で使う基本系列
- `X` 系列:
  - `A` 系列を、生成AIが誤解しにくいように精密化した系列
- `S` 系列:
  - `A` 系列の流れから自然に派生する新規候補を提案する系列
- `P` 系列:
  - 世間で広く使われている定番プロンプトを整理する系列

## 期待する性質

- 普及度や定番性がある
- このリポジトリの利用者にとっても再利用価値がある
- まだ `A` 系列に入っていなくても違和感がない
- 世間的な型として理解しやすい
- 将来的に `A` 系列へ取り込むかどうかを見極めやすい

## 運用イメージ

`P` 系列では、たとえば次のようなものを扱います。

- 世間でよく見かける要約プロンプト
- 比較表、FAQ、議事録、アジェンダ化のような定番変換プロンプト
- 非技術者向け説明や平易化のような普及度の高い説明系プロンプト
- 形式固定出力や一般的な抽出系プロンプト

一方で、次のようなものは `P` 系列より他系列が適しています。

- 自分の実務で日常的に使う正本:
  - `A` 系列
- `A` 系列の AI 向け詳細版:
  - `X` 系列
- `A` 系列から自然に派生した新規候補:
  - `S` 系列

この意味で `P` 系列は、自分の現場の正本ではないが、世間的な普及度と再利用価値を持つプロンプトを管理するための枠です。
