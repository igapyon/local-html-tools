# prompt-definitions-ai-suggest

`docs/prompt/src/prompt-gen/ts/prompt-definitions-ai-suggest.ts` は、既存 `A` 系列や `X` 系列の流れを踏まえて、自然に追加されそうな新規候補を提案する `S` 系列の定義を配置するためのファイルです。

## 役割

`S` 系列は、既存プロンプト群をそのまま精密化する系列ではありません。  
既存の並び、番号帯、目的感、作業フローを踏まえたときに、「次の一手として自然に存在しそうな新規候補」を生成AI視点で提案する系列です。

これは単なる思いつきの新規案ではありません。  
既存系列との連続性を保ちながら、まだ人間が明示的には作っていないが、実務上は追加価値がありそうな候補を発想し、文章化することを目的とします。

## 基本的な考え方

- 既存 `A` 系列の目的感や流れを踏まえる
- `X` 系列のような精密化ではなく、新規候補の提案を行う
- 既存プロンプト群の周辺に自然に存在しそうな候補を考える
- 人間が読んでも納得できる目的感を持たせる
- 生成AIがそのまま候補案として使える粒度まで具体化する

## 既存系列との関係

- `A` 系列:
  - 基本系列。人間にとって自然で簡潔な依頼文
- `X` 系列:
  - `A` 系列を、生成AI向けに誤解しにくく精密化した系列
- `S` 系列:
  - `A` 系列や `X` 系列を見たときに、次に自然に追加されそうな新規候補を提案する系列

したがって `S` 系列は、既存系列を置き換えるものではなく、既存系列の周辺にある未定義の候補を見つけて提示する補助系列として位置づけます。

## 期待する性質

- 既存系列と連続性がある
- 単なる思いつきではなく、実務上の追加価値がある
- 人間にも意図が理解しやすい
- 生成AIがそのまま候補案として扱える
- ラベル、keywords、本文案まで具体化されている

## 番号の考え方

`S` 系列では、どの `A` 系列から着想した候補かを示したい場合に、`S101-001` のような枝番形式を使います。

- `S101-001`
  - `A101` 系列からインスパイアされた 1 件目の suggest 候補
- `S101-002`
  - `A101` 系列からインスパイアされた 2 件目の suggest 候補

この形式により、既存基本系列との関係性を視覚的に把握しやすくします。

## 運用イメージ

`S` 系列は、たとえば次のような場合に有効です。

- 既存のボタン群を見たときに、隙間になっている候補を追加したい
- ある番号帯の流れに沿って、次に自然な候補を考えたい
- 人間がまだ明示していないが、生成AI的にはよく必要になる補助タスクを候補化したい
- 実務上ありがちな「次の一手」を prompt として定義したい

この意味で `prompt-definitions-ai-suggest.ts` は、既存系列を精密化する場所ではなく、既存系列の流れから自然に派生する新規候補を管理するためのファイルです。
