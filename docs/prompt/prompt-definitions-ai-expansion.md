# prompt-definitions-ai-expansion

`docs/prompt/src/prompt-gen/ts/prompt-definitions-ai-expansion.ts` は、既存 `prompt-definitions.ts` の延長上にある `X` 系列の定義を配置するためのファイルです。

## 役割

`X` 系列は、元のプロンプト系列と目的を大きく変えずに、生成AIが誤解なく解釈しやすいように緻密化した系列です。

これは単なる言い換えや冗長化ではありません。  
元のプロンプトが持っている目的、期待する成果物、背景にある意図を保ちながら、生成AIが曖昧に解釈しやすい部分を減らし、より安定して実行しやすい形へ展開したものです。

## 基本的な考え方

- 元の系列と目的感は大きく変えない
- 生成AIが誤解しやすい部分を具体化する
- 手順、判断軸、前提、期待する成果物を明確にする
- 生成AIが安定して実行しやすい形にする
- ただし、人間が読んでも意図が分かる説明性を維持する

ここでいう「人間が読んでも意図が分かる説明性」は、人間のためだけに残しているわけではありません。最近の生成AIは、目的、背景、期待効果のような文を、判断に迷ったときの優先順位づけや作業意図の補助線として利用する傾向があります。そのため `X` 系列では、必要に応じて人間向けにも自然な目的文や効果の説明を残します。これは生成AIの解釈を安定させる助けにもなります。ただし、同趣旨の説明を過剰に増やすとトークン数を圧迫して逆効果になりうるため、重複は避け、意味のある補助文だけを残す方針とします。

## 元系列との関係

- 元系列:
  - 人間にとって自然で簡潔な依頼文
- `X` 系列:
  - 同じ目的を、生成AIがより安定して実行できるように精密化した版

したがって `X` 系列は、元系列を置き換えるものではなく、元系列の目的を共有しつつ、生成AI向けの解像度を上げた補助系列として位置づけます。

## 期待する性質

- 元のプロンプトと連続性がある
- 人間にも読める
- 生成AIにとって曖昧さが少ない
- 手順や期待成果物が明確である
- 元の系列よりも、実行時の解釈ぶれが小さい

## 運用イメージ

`X` 系列は、既存プロンプトの目的を維持しつつ、次のような場合に有効です。

- 元の文面では生成AIの解釈がぶれやすい
- 期待する成果物をもう少し明示したい
- 生成AI向けに中間形式・詳細版として展開したい
- 元のプロンプトを、より安定した実行用に深掘りしたい

この意味で `prompt-definitions-ai-expansion.ts` は、既存系列の新規発明だけを置く場所ではなく、既存系列を生成AI向けに展開・精密化した候補を管理するためのファイルです。
