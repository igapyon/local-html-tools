            ローマ字の3層モデル（なぜ OSAKA / OHNO が起きるか）
            

              

                規範（方式）
                ヘボン式・訓令式・日本式のような「基準ルール」。
              

              

                実務運用
                旅券や標識のように、読みやすさ・実務都合で長音省略や慣例を使う層。
              

              

                慣用（固有名詞）
                人名・地名・組織名で定着した綴り。規範より慣用が優先される場合がある層。
