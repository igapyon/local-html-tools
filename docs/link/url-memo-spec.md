# URLメモ 仕様メモ

`docs/link/` 配下に追加する予定の、URL を一覧管理する single-file web app の仕様検討メモ。

アプリ名は `URLメモ` とする。配置パスは `docs/link/` を前提とする。

## 目的

- URL をローカルで一覧管理する
- URL に対して、タイトル、メモ、キーワードを紐づけて再利用しやすくする
- 検索起点で絞り込み、必要な項目だけ詳細表示できるようにする
- ブラウザのみで動作し、`localStorage` に保存する

## 形式

- 単一 HTML のローカル Web アプリ
- このリポジトリの `docs/link/` 配下に配置する
- 配布物は single-file web app とする
- 保存先は `localStorage`
- Import / Export に対応する
- 共通部品は `lht-cmn` を利用する
- デザイン基調は MD3 ベースとする

## UI 方針

- 検索体験は `docs/prompt/prompt-gen.html` を参考にする
  - 上部に検索欄を置く
  - 検索入力に応じて候補を絞り込む
  - 一覧は薄く保ち、選択後に詳細を見る流れにする
- ダイアログやボタンの扱いは `docs/git/git-work-list.html` を参考にする
  - 登録 / 編集ダイアログ
  - 主要操作ボタン
  - Import / Export
  - アクション導線

つまり、検索 UI の骨格は `prompt-gen`、操作系コンポーネントの流儀は `git-work-list` を意識したハイブリッド構成とする。

## データ項目

1 件あたり次を持つ。

- `title`
  - 一覧表示用のタイトル
- `url`
  - 対象 URL
- `memo`
  - 自由記述メモ
- `keywords`
  - 配列
- `createdAt`
  - 作成日
- `lastAccessedAt`
  - 最終アクセス日

## 一覧 UI

- 検索インタフェースは `docs/prompt/prompt-gen.html` の流儀を参考にする
- 上部に 1 本の検索欄を置く
- 入力に応じて候補を一覧表示する
- 一覧にはタイトルのみ表示する
- 一覧項目をクリックすると詳細表示する

## 詳細表示

- クリック時に詳細表示する
- 詳細には少なくとも次を表示する想定
  - タイトル
  - URL
  - メモ
  - キーワード
  - 作成日
  - 最終アクセス日
- 編集、削除、URL を開く導線を詳細表示から提供する想定

詳細表示の UI 形状は未確定。候補は次のいずれか。

- モーダルダイアログ
- 画面下部の詳細ペイン

現時点では、一覧を薄く保つ方針のため、モーダルダイアログの相性がよさそうである。

## 操作

- 追加
- 変更
- 削除
- 並び替え
- 検索
- Import
- Export

## 検索

- タイトル、URL、メモ、キーワードを検索対象に含める想定
- 検索 UI は `prompt-gen` の候補検索に近い体験を目指す

### 並び順

- 検索結果はヒット率順
- 同率または通常表示時は `lastAccessedAt` の降順

### ヒット率の考え方

詳細な重みづけは未確定だが、現時点では次の方向を想定する。

- タイトル一致: 強
- キーワード一致: 強
- メモ一致: 中
- URL一致: 弱

## 日付項目

- `createdAt`
  - 登録時に設定する
- `lastAccessedAt`
  - URL を開いたときに更新する想定

## Import / Export

- JSON 形式で Import / Export する
- `git-work-list` や `prompt-gen` に近い流儀に揃えるのが自然
- 少なくとも次を持つ想定
  - `version`
  - `exportedAt`
  - 本体データ

## 保存

- `localStorage` に保存する
- 一覧データの保存キーは今後決定する

## 現時点の理解

- アプリ名は `URLメモ`
- 配置は `docs/link`
- UI は `prompt-gen` 型の検索起点
- 一覧はタイトルのみ
- クリックで詳細表示
- データは `title`, `url`, `memo`, `keywords[]`, `createdAt`, `lastAccessedAt`
- 並び順は `ヒット率`、次に `最終アクセス日降順`
