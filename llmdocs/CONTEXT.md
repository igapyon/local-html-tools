# Project Context

## 目的

`local-html-tools` は、静的 HTML ファイルとして配布されるブラウザベースのローカルツール集です。主な目的は、サーバを必要とせずユーザーの手元の環境でそのまま動く実用的なユーティリティページを提供することです。

## 高レベルな目標

- 各ツールを自己完結した単一 HTML ページとして利用できる状態に保つ。
- 可能な限りローカルファースト、オフラインファーストの動作を優先する。
- `lht-cmn/` と `lht-*` コンポーネント層を通じて UI パターンを標準化する。
- 入力 -> 生成 -> コピー/反映 のような単純な利用フローを維持する。
- 配布物が単一 HTML であっても、保守しやすい開発フローを成立させる。

## 技術スタック

- 静的 HTML、CSS、JavaScript
- 一部モジュールでは TypeScript を利用。特に `docs/music/` と `docs/prompt/` が中心
- `scripts/` 配下の Node.js ビルドスクリプト
- バンドル補助としての `esbuild`
- テスト用の `vitest` と `jsdom`
- 必要に応じて `lht-*` 抽象化の背後で利用する Material Web

## 制約

- 配布されるツールは静的ファイルのまま、ブラウザで直接開ける必要がある。
- 多くのツールは生成後に完全オフラインで動作できることが望ましい。
- 生成済みの `*.html` はビルド成果物であることが多く、直接編集しない。
- 複数の領域で `*-src.html` と分割ソースを使い、最終的に単一 HTML を生成する構成を採用している。
- UI の正本は direct な `md-*` 利用ではなく `lht-cmn/` に置く。

## 開発方針

- 最小限で対象を絞った変更を優先する。
- 保守性のためにソースを分割しても、配布形態は単一ファイルを維持する。
- 繰り返し登場する UI 挙動は `lht-cmn/` に集約する。
- 実装上の判断や現在の作業状況とドキュメントを同期させ続ける。
