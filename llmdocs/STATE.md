# Current State

## 概要

このリポジトリの骨格ドキュメントは、ルートの `README.md`、`ARCHITECTURE.md`、`TODO.md` と、`llmdocs/` 配下の要約・運用文書で役割分担する形へ整理された。

## 現在の理解

- これは単一アプリではなく、複数ツールから成る静的 Web アプリ集のリポジトリである
- 多くの `docs/*/*.html` は配布用生成物であり、`*-src.html` や `src/` が存在する場合はそちらが正本である
- 共有 UI の標準化は現在も主要テーマであり、`lht-cmn/` を中心に横展開を続けている
- `llmdocs/` はルート文書の置き換えではなく、短い運用レイヤーとして扱う

## 既知の問題

- 一部の UI 挙動は、まだアプリページごとに重複している
- 狭幅画面でのはみ出しや表示崩れは、個別対応済みの箇所がある一方で、引き続き横展開確認が必要である
- Material Web 由来の初期化癖や警告は一部画面で残っており、共通ルールだけで吸収できるか継続確認が必要である

## 最近の判断

- ルート `TODO.md` は中長期バックログ、`llmdocs/TODO.md` は直近の作業キューとする
- ルート `ARCHITECTURE.md` を正本とし、`llmdocs/ARCHITECTURE.md` は LLM 向け要約版とする
- `GLOSSARY.md` を、現行アーキテクチャと運用語に合わせて補強する
- サードパーティ通知は、実際に同梱・利用している依存に合わせて更新する

## 最近の変更

- ルート `README.md` を実ファイル構成とビルド運用に合わせて更新した
- `THIRD_PARTY_NOTICES.md` に `@material/web`、JSZip 配下の `pako`、既知バージョン情報を反映した
- ルート `ARCHITECTURE.md` を全体設計書として再構成し、配布モデル、ビルド、開発モード、画面パターンを整理した
- `GLOSSARY.md` に `lht-cmn`、`lht-*`、`single-html`、`分割ソース型` などの運用語を追加した
- ルート `TODO.md` と `llmdocs/TODO.md` を役割分担に沿って整理した
- `README.md` と `llmdocs/RULES.md` に、2 系統の TODO の使い分けを明記した
- `llmdocs/ARCHITECTURE.md` を、重複した第二の設計書ではなく、正本への短い要約導線へ整理した
