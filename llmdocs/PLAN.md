# Project Plan

## 目標

- 一貫した UI とビルド挙動を持つ、整合的なローカルファーストのツール集を維持する。
- 繰り返し利用される UI パターンの `lht-cmn/` への集約を進める。
- 保守しやすいソースから生成 HTML を再現可能な状態に保つ。

## 現在のマイルストーン

- 今後の LLM 支援作業に向けて、`llmdocs/` をリポジトリの記憶レイヤーとして定着させる。
- `lht-*` 採用を継続し、アプリページ内の raw `md-*` 利用を減らす。
- toast、error、ファイル選択、プレビュー、コマンド表示などの共有挙動を標準化する。
- 全ツールドメインでビルドとテストの信頼性を維持する。

## 今後の作業

- 共有 `lht-cmn` コンポーネントの全アプリ横展開を完了する。
- 特に狭幅画面でのはみ出しを中心に、残っているレスポンシブレイアウト課題へ対応する。
- バックログにある追加のコマンド生成ツールやユーティリティページでツール群を拡張する。
- ドメインごとの作業が進むたびに、アーキテクチャとタスク記憶を最新に保つ。
