## はじめに

生成AIを Web UI で使っていると、プロンプトの管理が意外と煩わしい手作業になりがちです。  
私も、メモやテキストファイル、IME 登録などで何とか回していましたが、だんだんそれがつらくなってきました。

そこで、生成AIプロンプトを数文字の断片入力で絞り込んで利用できる `prompt-gen` というアプリを作りました。

## 何を扱う記事なのか

この記事では、`prompt-gen` というアプリの紹介と、なぜこの形の入口を作ったのかを書きます。

品揃えをどう増やしたかや、プロンプト系列をどう分けて管理しているかといった話は、今回は深入りしません。  
まずは「プロンプトへ素早く辿り着く入口をどう作ったか」に絞ります。

## なぜそれが必要なのか

もともとは、メモ、テキストファイル、IME 登録などでプロンプトを運用していました。  
はじめるだけなら、どれも十分便利です。実際、私もそうやって回していました。

ただ、使うプロンプトが増えてくると、だんだん小さなフラストレーションが積み重なってきました。

- どこに置いたかを探す手間があります
- 正本が分からなくなることがあります
- 文面が増えると探しにくくなります
- 目的に応じて少しずつ直すのも地味に負担です

さらに、IME 登録は便利ではありましたが、増やしていくと通常の変換に支障が出てきました。  
一瞬は IME を自前で作ることも考えましたが、踏みとどまって `prompt-gen` の形にしました。

いちばん大きかったのは、とにかくプロンプトを探す手間を減らしたかったことです。

## どう動くのか / どう作ったのか

`prompt-gen` の入口はかなり単純です。

まず、「やりたいこと」に近い断片を入力します。  
すると、その断片に合いそうなプロンプト候補が絞り込まれます。そこから使いたいものを選んで、そのまま使います。

そのため、なにやら分類画面を作るとか、ではなく、とにかく断片入力から候補を引ける形を目指しました。  
やりたいことに近い語を数文字入れれば候補に辿り着ける方が、自分の欲しい使い方だったのです。

自分の中で正確な名前を覚えていなくても、数文字の断片から辿れるようにしたかったので、入口がこのようになるよう作りました。  
また、一部のものはローマ字でも引けるようにしているので、日本語の語をローマ字で思い出している時にも IME 変換を飛ばして利用できるのが私には便利です。

さらに、出力オプションの並びもかなり気に入っています。  
Markdown 出力、文体、幻想防止、自己レビュー、最小差分、誤解表現、配慮不足、不快感、攻撃性、センシティブ、法令遵守、公序良俗といった観点を並べていて、生成AIプロンプトのバリエーションをクリック 2 回で切り替えられるようにしています。

プロンプト本文を毎回書き換えるのではなく、ベースになるプロンプトを選んだうえで、こうした観点を後から切り替えられるのは、自分の使い方にはかなり合っていました。

## 具体的にできること

- プロンプト集から候補を検索できます
- 数文字打つだけで候補を絞り込めます
- 一部のものはローマ字入力でも引けます
- 画面状態やカスタムプロンプトを JSON で Import / Export できます

「やりたいこと」にほしいプロンプトの断片を入れて候補へすばやく辿り着けることを重視しました。  
たったこれだけのものですが、本人的にはとても気に入って使って育てています。

## 制約と今後

今回は、`prompt-gen` の紹介と、検索ベースの入口を作った背景に絞りました。  
そのため、次のような話は別記事に回す前提です。

まだ育てている途中のアプリなので、今後も使いながら少しずつ改善していくつもりです。

## まとめ

`prompt-gen` は、散らばりがちな生成AIプロンプトを探しやすくするために作ったアプリです。

まずは、数文字の断片入力から候補を絞り込める入口を作ることを優先しました。  
その結果、少なくとも「どこに置いたかを探してコピペする」手間はかなり減らしやすくなりました。

さらに、出力オプションを並べておくことで、ベースのプロンプトを選んだあとにバリエーションを切り替えやすくしています。  
生成AIプロンプトの運用が手作業に寄ってきた時の、最初の整理先としては悪くない形になってきたと感じています。
