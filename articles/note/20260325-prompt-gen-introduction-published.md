# 生成AIのプロンプト探しが地味に面倒だったので、小さなアプリを作りました

生成AIを使っていると、プロンプトを考えることそのものより、使いたいものを探す時間のほうが気になることがあります。手元に置いたメモを探したり、前に見かけたものをネットでもう一度探したり、前に作ったお気に入りのプロンプトを思い出せなかったりします。どこかに記録したはずなのに見つからないこともあって、それだけで少し疲れてきます。  
そこで発想を少し変えて、まずは探しやすくするための小さなアプリを作りました。

実際に使える URL は次のとおりです。  
<https://igapyon.github.io/local-html-tools/prompt/prompt-gen.html>

最初は、とにかくプロンプトを溜めていけば何とかなると思っていました。でも、溜めるだけではやっぱり探しにくい。とはいえ、しっかりした検索システムを作りたいわけでもありませんでした。むしろ、検索ボタンを押すひと手間すら面倒です。そこで、文字を少し打つだけで、手元にあるプロンプトがぐっと絞られていくような小さな仕組みにしました。さらに、かな漢字変換もだんだん面倒になってきて、一部はローマ字のままでも探せるようにしました。

それから、私はこういうものをわりと見失いがちなので、アプリと一緒に使うプロンプト集は GitHub に置くことにしました。公開しておけば、少なくともどこかに埋もれて分からなくなる感じは減ります。探しやすくするために作ったものなのに、その元になるプロンプト集が見つからなくなったら元も子もないので、なくしにくい置き場所にしておきたかったのです。

立派な仕組みを作ったわけではありません。でも、毎回ひっかかっていた小さな面倒が少し減るだけで、それだけでちょっとうれしいものだなと思っています。

関連記事として、アプリ自体の紹介や細かな話は Qiita にも書いています。  
技術寄りの話が気になる方は、そちらを見ると雰囲気が伝わりやすいかもしれません。
